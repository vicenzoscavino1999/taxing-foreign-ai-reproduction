# Coverage of the base reproduction

The base analysis covers 39 operations in 14 families. Seventeen recompute numerical results from model inputs, twelve regenerate outputs from stored inputs, and ten verify the integrity of archived results. The `plan` action lists the operations and `full` runs them. The public plan groups units that share a costly ceiling so the calculation can be reused within a process.

The full base analysis was completed across successive runs on 19–21 November 2026. The public release was tested with a pilot on a clean Windows installation and selected additional runs. The [archived run record](https://github.com/vicenzoscavino1999/taxing-foreign-ai-reproduction/blob/v1.0.0/docs/FULL_RUN_HISTORY.md) documents the evidence by family.
